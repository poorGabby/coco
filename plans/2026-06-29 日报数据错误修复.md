### 🔴 Bug 1: WAU = 0 → Root Cause CONFIRMED

WAU chart `by4be2r4` headers are weekly: `2026-06-22, 2026-06-29` with values `155, 11`.
Code matches `2026-06-28` and `2026-06-27` against weekly headers → no match → falls back to last 2 columns.
Last column is `2026-06-29` (current incomplete week = 11), compared to `2026-06-22` (155).
**Fix:** In the weekly fallback inside `extractTimeseries`, skip the current incomplete week and use the last 2 full weeks: 155 vs 163.

### 🟡 Bug 2: Retention No WoW

`extractRetention` always sets `dayBefore: null`. Need a cache to store yesterday's retention values.
