# Plan: Feishu Bot — 占位消息 + 对话记忆

## Context

用户在飞书群里 @机器人 提问后，需要等待 5-15 秒（Amplitude 数据拉取 + 知识库检索 + Gemini LLM 推理）才能看到回复。这期间没有任何反馈，体验很差。

另外，机器人每次对话都是"失忆"的——不会记住上一轮说了什么，导致追问"那昨天呢？"时无法理解上下文。

**目标：**
1. 收到消息后立刻回复"正在查询数据，请稍候…"占位消息
2. 按 chat 维度记住最近 N 轮对话，追问时可自然引用上文

## 1. 新建 `conversation.ts`

**数据结构：**
```ts
interface ConversationStore {
  messages: { role: "user" | "assistant"; content: string }[];
  lastActivity: number;
}
const store = new Map<string, ConversationStore>();
```

**常量：**
- `MAX_MESSAGES = 20`（10 轮对话）
- `TTL_MS = 30 * 60 * 1000`（30 分钟无活动过期）
- `CONTENT_MAX_LEN = 2000`（单条截断）
- 定时清理 interval 5 分钟（`timer.unref()` 不阻止进程退出）

**导出函数：**
- `addMessage(chatId, role, content)` — 追加消息，超出上限删最旧 2 条
- `getHistory(chatId, maxTurns?)` — 返回 `ConversationMessage[]`，过期返回 `[]`
- `formatHistoryForPrompt(chatId, maxTurns?)` — 格式化为中文 prompt 文本
- `evictStaleConversations()` — 定时清理
- `clearAll()` / `stats()` — 调试用

**设计要点：**
- 纯同步操作 Map，Node.js 单线程无竞态
- 重启 / Cloud Run 缩容时数据丢失（预期内）
- 内容截断防内存膨胀

## 2. 修改 `ask.ts`

**`askQuestion` 签名变更：**
```ts
export async function askQuestion(
  env: Env,
  question: string,
  conversationContext?: string,  // 新增：可选，由调用方预格式化
): Promise<AskResult>
```

**userPrompt 组装（[ask.ts:182-193](apps/hermes/src/ask.ts#L182-L193)）：**
对话历史放在最前面（提供连续性），然后是知识库、数据、用户问题：
```ts
const userPrompt = [
  conversationContext ? `${conversationContext}\n\n---` : "",
  wikiResult.wikiText ? `以下是飞书知识库…` : "",
  `以下是 Amplitude 产品数据：\n\n${dataContext}`,
  `---\n\n用户问题：${trimmed}`,
  // ... 指令
].filter(Boolean).join("\n\n");
```

不修改 `SYSTEM_PROMPT`——对话历史是 per-chat 的，属于 user prompt。

## 3. 修改 `index.ts`

**新 import：**
```ts
import { addMessage, formatHistoryForPrompt } from "./conversation.js";
```

**异步 handler 改动（[index.ts:142-187](apps/hermes/src/index.ts#L142-L187)）：**

```
void (async () => {
  try {
    ① await replyMessage(env, messageId, "正在查询数据，请稍候…");  // NEW

    const text = parseMessageText(...);

    ② if (text) addMessage(chatId, "user", text);                     // NEW

    if (wantsDailyReport) { /* 日报逻辑不变 */ }
    else {
      ③ const ctx = formatHistoryForPrompt(chatId);                   // NEW
      ④ const result = await askQuestion(env, text || "…", ctx || undefined);

      await replyMessage(env, messageId, reply);

      ⑤ addMessage(chatId, "assistant", result.answer);               // NEW
    }
  } catch (err) { /* 错误处理不变 */ }
})();
```

**时序设计考量：**
- ① 占位消息放在 try 最前面，失败会被 catch 捕获
- ② 用户消息在 `askQuestion` 之前保存——快速连问时后续消息能看到上文
- ⑤ 助手回复在 `replyMessage` 成功后保存——发失败了不写入历史
- `askQuestion` 抛出异常时用户消息已保存但无助手机器人回复→下轮 LLM 自然忽略孤立消息，无实际影响

## 验证方式

1. **本地启动：** `tsx apps/hermes/src/index.ts`
2. **占位消息：** 飞书私聊 @机器人任意问题，确认立刻出现"正在查询数据，请稍候…"再出现正式回复
3. **对话记忆：** 
   - 问："昨天 DAU 是多少？" → 得到数字
   - 追问："那前天呢？" → 应理解为"前天的 DAU"而非重新问
   - 等 30 分钟后再问 → 历史应过期，追问行为退化为独立问题
4. **调试端点：** `GET /debug/events` 已有；新增 `GET /debug/conversations` 查看对话统计
