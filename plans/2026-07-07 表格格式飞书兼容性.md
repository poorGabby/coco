# Fix: Table Formatting for Feishu Compatibility

## Context

[HERMES_EXPANSION_PLAN.md](HERMES_EXPANSION_PLAN.md) 中的 Markdown 表格粘贴到飞书文档时格式错乱。根因是飞书 Markdown 解析器对表格内的内联格式（`**bold**`、`` `code` ``）和多行表格行支持有限。

## 需要修改的表格（共 5 处）

| # | 位置 | 问题 |
|---|------|------|
| 1 | L13-22 当前状态表 | `**bold**` 在单元格内不可靠 |
| 2 | L34-41 Gmail 权限表 | 多行行（L37-38 是同一行拆开）、`` `code` `` 在单元格内 |
| 3 | L93-99 PostgreSQL 表 | `` `code` `` 在单元格内、分号串联多个值 |
| 4 | L139-145 RevenueCat 表 | `` `code` `` 在单元格内 |
| 5 | L179-183 Typeform 表 | `` `code` `` 在单元格内 |

## 修改规则

1. **移除所有 `` `code` `` 反引号** → 替换为中文书名号「」或直接去掉
2. **移除单元格内 `**bold**`** → 替换为普通文本
3. **合并多行表格行** → 每行必须是一行，不能换行续写
4. **避免单元格内出现 `|`** → 如有则替换为 `、` 或 `/`
5. **保持表格前有空行** → 飞书需要空行来识别表格起始
